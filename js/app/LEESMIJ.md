# Broncode van de app (js/app.js)

De schermen van Helder staan hier in stukken, per onderdeel (Overzicht, Bank, Voorschotten, …).
Samen vormen ze één script: `js/app.js`. Apart zijn de stukken geen geldig JavaScript.

- **Iets wijzigen?** Pas het juiste stuk aan en voer daarna uit: `npm run build:app`
- **Volgorde:** het nummer vooraan bepaalt de volgorde. Een nieuw stuk krijgt een nummer tussen twee bestaande
  (hernummer gerust).
- De tests controleren dat `js/app.js` exact overeenkomt met deze stukken.
